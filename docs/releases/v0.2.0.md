- 全新「资源 / Agent / 动态 / 设置」界面，支持顶栏与侧栏切换，浅色和深色主题同步优化。
- 简化服务器接入：密码连接后自动转为免密密钥，主机指纹与 SSH 配置授权在连接过程中逐步确认；修复按 Esc 意外丢失连接草稿的问题。
