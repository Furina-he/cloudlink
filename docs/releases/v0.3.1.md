- 执行模式调整为“确认变更／自动运维”：查询直接执行；确认变更的变更先问，自动运维仅直接执行范围内规则明确的常规变更。两档的高危或目标明确但解析不明的操作仍需允许一次，红线与目标不明仍拒绝。
- 升级后，原“只读巡检”和“标准运维”均转为“确认变更”；自动运维需要重新选择，不静默提升权限。新资源默认确认变更，生产标记独立，生产启用自动运维需确认。
- 修复共用目录分发：点谁只改变谁的选择，实际副本只提供共同选择的交集；部分送达与无法单独提供如实说明，同名 Agent 的独立目录不再互相覆盖内容。
- 动态、审批和执行记录按实际调用来源显示品牌，未知来源不再猜成 Claude Code；自报明确标注，继续等待审批和执行结果保留原来源与会话。
- GitHub 新接入默认自动跟随，已有手动范围保持不变；分别展示登录有效性与仓库范围核对状态，减少重复身份信息和刷新入口。
- 修复 Windows runner 的无效 WSL 路径及托盘档位切换；生产与非生产资源统一引导执行入口，不放宽路径校验。
- 使用边界：CloudLink 运行中（含托盘）继续检查；彻底退出后 Skill、执行入口和新操作仍可用，但停止检查与审批。旧的未启动审批不因退出获批，策略损坏或通信异常也不当作退出放行。护栏不能替代远端权限或安全沙箱。
